codes.train.tasks module#

Run individual training tasks independently of their scheduler.

codes.train.tasks.execute_training_task(task, *, device='cpu', position=0, cpu_threads=1)#

Configure a worker process and train and save exactly one model.

task contains (surrogate, mode, metric, training_id, seed, epochs), as produced by create_task_list_for_surrogate. The saved configuration is read from trained/<training_id>/config.yaml. device is a logical device string within the worker’s allocation; cpu_threads sets PyTorch’s intra-operation thread count.

Local spawned processes and future external workers can both call this function. It propagates errors and does not update pending-task files or completion markers; those belong to the scheduler invoking it.

codes.train.tasks.train_and_save_model(surr_name, mode, metric, training_id, seed=None, epochs=None, device='cpu', position=1, threadlock=None)#

Train and save a model for a specific benchmark mode.

Parameters:

  • surr_name (str) – The name of the surrogate model.

  • mode (str) – The benchmark mode.

  • metric (int) – The metric for the benchmark mode.

  • training_id (str) – The training ID for the current training session.

  • seed (int | None) – Random seed for training.

  • epochs (int | None) – Number of training epochs.

  • device (str) – Device to run training on.

  • position (int) – Model position in the task list.

  • threadlock (optional) – Legacy lock used around seeded initialisation.

codes.train.tasks.validate_execution_settings(device, cpu_threads)#

Validate worker settings without selecting a CUDA context.

CUDA indices are logical indices within the process’s visible devices. CPU threads must fit within both its affinity mask and any Slurm allocation.
